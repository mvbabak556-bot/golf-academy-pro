## ۱) پیش از ارائه — نصب فونت‌ها (مهم)

اسلایدها با سه فونت رسمی خواسته‌شده طراحی شده‌اند و باید روی همان سیستمی که
ارائه می‌دهید نصب باشند:

| کاربرد | نام فونت |
|---|---|
| تیترهای اصلی | **B Titr** |
| تیترهای فرعی / تأکیدی | **B Lotus** |
| متن اصلی و جدول‌ها | **B Zar** |

اگر روی سیستم ارائه فونت‌ها نصب نباشند، پاورپوینت فونت جایگزین می‌گذارد و
چیدمان به‌هم می‌ریزد. پس از نصب فونت، یک‌بار فایل را باز و ذخیره کنید.
برای جابه‌جایی امن می‌توانید از `File → Export → PDF` هم خروجی بگیرید.

## ۳) چه داده‌هایی واقعی است و چه چیزهایی باید تکمیل شود؟

**داده‌های واقعیِ مستخرج از چکیده (بدون تغییر):**
روش «کاربردی / توصیفی همبستگی»، جامعهٔ **۲۴۵ نفری**، **۱۵۰ پرسشنامه** بر
مبنای جدول مورگان، نمونه‌گیری **تصادفی طبقه‌ای + خوشه‌ای**، روایی به تأیید
استادان و خبرگان، آلفای کرونباخ **۰/۹۲۲ (۹۲٫۲٪)**، آزمون نرمال‌بودن
**کولموگروف–اسمیرنوف**، آزمون فرضیه‌ها با **اسپیرمن در SPSS** و تأیید وجود
**رابطهٔ معنادار در همهٔ فرضیه‌ها**.

**جای‌نماها (هیچ عددی اختراع نشده است):**
هر متنی داخل براکت `[ ... ]`، هر کادر خط‌چین طلایی/کرم، و خانه‌های `[درج]`,
`[r]`, `—` در جدول‌ها و نمودارها عمداً خالی گذاشته شده‌اند تا داده‌های دقیق
پایان‌نامه (به‌ویژه ضرایب **r** و سطوح **p** فصل ۴، جدول توصیفی، منابع و
یافته‌های پیشین و متن پیشنهادها/محدودیت‌های فصل ۵) در آن‌ها قرار گیرد.

> توصیهٔ ترتیب تکمیل: ۱) جدول اسلاید ۱۵ (r و p هر چهار فرضیه) →
> ۲) نمودار اسلاید ۱۴ → ۳) جدول و نمودارهای اسلاید ۱۶ → ۴) جدول پیشینهٔ
> اسلاید ۹ → ۵) ستون مقایسه و تفسیر اسلایدهای ۱۷–۱۸ → ۶) متن پیشنهادها و
> محدودیت‌ها.

## ۴) نکات ارائه

- برای هر اسلاید، **متن سخنرانی (Presenter Notes)** به‌صورت فارسی درون خود
  فایل پاورپوینت نوشته شده است (در حالت Presenter View دیده می‌شود).
- صفحهٔ عنوان: نام استاد مشاور، رشته و تاریخ دفاع با براکت مشخص شده‌اند.
- اعداد داخل اسلایدها فارسی‌اند؛ در جدول‌های آماری می‌توانید بنا به سنت
  پایان‌نامه اعداد لاتین خروجی SPSS را عیناً جای‌گذاری کنید.

## ۵) بازتولید (برای ویرایش‌های برنامه‌ای)

```bash
pip install python-pptx pillow numpy arabic-reshaper python-bidi
python3 prep_assets.py     # برش و پردازش تصاویر AI → assets/proc
python3 build_deck.py      # ساخت PPTX و رشته‌تصاویر پیش‌نمایش qa/slides
```

- `build_deck.py` تعریف محتوای اسلایدها؛ `deck_lib.py` موتور طراحی مشترک.
- پیش‌نمایش همهٔ اسلایدها: `qa/contact_sheet.png`.
- تصاویر با هوش مصنوعی و در پالت یکپارچهٔ سرمه‌ای/سبز کهربایی تولید شده‌اند
  (پوشهٔ `assets/`).
